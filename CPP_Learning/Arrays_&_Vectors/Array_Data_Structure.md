## What are data structures?
// Data structures are that ways to store data in a format that it can be accessed efficiently and more easily.

## Algorithms
// Algorithms are processes which are used to access that data.


## What is a Array?
// Array is a data structure we use to store data of same type.

    ---------------------------------------
    |   data    |    data    |    data    |
    ---------------------------------------

// Array can only store data of same type
// Array is a linear data stricture
// Array is contiguous(continuos) in memory
// We can access vals in an array through its index

## Syntax of an Array

data_type arr[size] = {element_1, element_2};

e.g:
int marks[5] = {88, 77, 66, 87, 99};
